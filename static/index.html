THE ORIGINAL APPROACH

Research architecture

Academic PDF→SentenceSplitter→BGE embeddings→VectorStoreIndex→Zephyr-7B-beta→Telegram

Paper: node sekitar 128 token, tiga hasil retrieval teratas. Pengujian awal Llama 3 dan Qwen menjadi bahan evaluasi sebelum rancangan RAG.

THIS NEW PORTFOLIO BUILD

Reimagined for the web

Website ini implementasi ulang untuk portofolio: FastAPI + HTML/CSS/JS + TF-IDF retrieval + Ollama LLM. Jika dipilih, retrieval embedding semantik Ollama dapat diaktifkan. Ini bukan deployment aplikasi Telegram asli dan tidak terhubung ke SIAKAD.
